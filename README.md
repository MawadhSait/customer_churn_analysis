# Customer Churn Analysis Using SQL

## Project Overview

This project analyzes customer churn to understand why customers leave the service and identify patterns associated with churn.

## Project Objectives

- Measure overall customer churn.
- Compare churn across customer segments.
- Analyze customer behavior.
- Identify high-risk customers.

## Dataset and Tools

- **Dataset:** Customer Churn Dataset from Kaggle
- **Database:** SQLite
- **Tools:** Python, Pandas, SQL

## Business Insights

1. **Contract Risk:** Monthly-contract customers showed unusually high churn.
2. **Subscription Risk:** Basic subscriptions had the highest churn rate.
3. **Customer Value:** Churned customers had lower average spending.

## Business Recommendations

- Investigate monthly-contract churn.
- Improve customer support.
- Develop customer retention strategies.

## Limitations

- The analysis identifies associations, not causation.
- Unusual churn rates require further validation.
